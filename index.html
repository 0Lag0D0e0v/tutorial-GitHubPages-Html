Linguagem HTML

HTML é uma linguagem de marcação

HTML5
  • É uma linguagem de marcação utilizada na construção de páginas na web. Define o significado e a estrutura do conteúdo da web. Outras tecnologias além do HTML geralmente são usadas para descrever a aparência/apresentação (CSS) ou a funcionalidade/comportamento (JavaScript) de uma página da web.
  • É a quinta versão da linguagem HTML.
  • A tecnologia é uma junção entre os padrões HYTime e SGML.
  • HYTime é um padrão a representação estruturada de hipermídia e conteúdo baseado em tempo.
